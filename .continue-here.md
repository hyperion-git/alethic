## What This Feature Is

Two new commands for the Alethic reasoning agent:
- **`alethic verify`** / `/alethic-verify`: Takes problem + solution, runs K independent verifiers in parallel, synthesizes a consensus report. "Does this correctly solve the stated problem?"
- **`alethic check`** / `/alethic-check`: Takes solution only (no problem statement), runs K independent checkers, synthesizes consensus. "Is this reasoning internally valid?"

Both use multi-verifier consensus (K=2-7 depending on preset), mechanical aggregation (majority-vote verdict, mean confidence, issue union with vote counts), then LLM critique cleanup.

## Key Design Decisions Made

1. **verify** = problem+solution (correctness), **check** = solution only (internal consistency)
2. **Always multi-pass consensus** — K verifiers, preset-driven (quick=2, default=3, thorough=5, extreme=7)
3. **Hybrid synthesis** — mechanical aggregation (deterministic verdict/confidence) + LLM critique cleanup (one cheap call)
4. **Domain auto-detection** via static JSON dictionary (~500 terms/domain, 3 weighted tiers: strong=3, moderate=2, weak=1), with `--domain` override
5. **Tools**: verify/check default to `sympy,numpy,scipy,matplotlib`; solve/derive stay at `sympy,numpy`
6. **Two separate skills** following the thin-configurator pattern, sharing a `verify-orchestrator.md`
7. **Session directories** persist in `.alethic/` with flat worklog (no iter subdirs)
